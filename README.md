# Arabic–English Business Translation Glossary

A free, searchable bilingual glossary for University of Nizwa students, built only from instructor-provided course materials. Draft for instructor review.

- Sections: Glossary (173 terms), Translation Practice (course exercises with glossary hints), Review, About.
- Add or change terms or exercises: see GUIDE.md (edit glossary.json and exercises.json only).
- Publish on GitHub Pages: see PUBLISHING.md.
- Technology: HTML, CSS and JavaScript only. No accounts, no paid APIs, no build step.
